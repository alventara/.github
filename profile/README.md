### Hi, we're Alventara 👋

We're a Cairo-based cloud and software team and an **AWS Select Tier Services Partner**. We help startups across MENA get their product running well on AWS, and we help them use AWS programs so AWS can fund the work, not just the bill.

### What we do

| | |
|---|---|
| **AWS funding programs** | We check eligibility and prepare MAP, POC and Activate applications with you. |
| **AWS migration** | Move real workloads from other clouds or hosting to AWS, planned and costed in writing. |
| **Build on AWS** | Greenfield products, GenAI on Amazon Bedrock, data platforms and serverless apps. |
| **Managed services** | We run, secure and optimise your AWS environment after launch. |

### How we work

`Eligibility check` → `Sales discovery` → `Technical discovery` → `Delivery`

Delivery in **Arabic and English**, with in-Kingdom support in Saudi Arabia through our partner network.
